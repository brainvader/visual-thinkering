# UI コンポーネント仕様

## 1. Entity Node (矩形)

- **形状**: 角の丸い矩形 (shadcn/ui Cardベース)
- **色**: プライマリカラーの境界線
- **機能**: ラベルをダブルクリックで編集可能。

## 2. Relation Node (菱形)

- **形状**: 45度回転させた正方形。
- **実装**: `className="rotate-45"` を適用し、中のテキストのみ `-rotate-45` で戻す。
- **色**: セカンダリカラー（またはアクセントカラー）。

## 3. Role Edge (接続線)

- **機能**: 線の上に `EdgeLabelRenderer` を使ってロール名を表示。
- **編集**: ラベル部分をクリックすると Input フィールドが出現し、ロール名を変更できる。
